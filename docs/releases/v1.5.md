不常驻的 Windows 桌面工具：把 Clash Verge Rev 订阅里的节点各自开放成一个本地代理端口。

## 下载

- **PortPilot-v1.5-windows-amd64.exe** —— 单个文件，双击运行，不需要安装，也不会在它旁边生成任何文件。

系统要求：Windows 10/11 ＋ Microsoft Edge WebView2 运行时（Win11 与装了 Edge 的机器都有）。
不需要管理员权限。

> 首次运行未签名程序时，Windows 可能提示「无法验证发布者」，点「运行」即可；此后再打开不再提示。

## v1.5 修复：窗口拖不动、边框与图标

这一版集中修窗口外壳，都是长期存在、但平时不容易归因的问题。

**1. 窗口顶部拖不动**

**原因**：拖动原本是前端 mousedown → Go 同步 `SendMessage(WM_NCLBUTTONDOWN, HTCAPTION)`。这条消息是在 WebView2 的消息处理里发起的，窗口的移动回路会立即退出——表现就是按住拖动毫无反应。

**修法**：改为参考项目 macUI-SolidGlass 的做法——宿主声明 `CSSDragProperty=--wails-draggable`，界面用 `--wails-draggable: drag` 标注可拖区域（侧栏 chrome、侧栏头部、内容区顶部 48px 拖拽带、工具栏标题区），按钮/输入框/导航等交互元素统一 `no-drag`。Wails 运行时会在鼠标**移动后**才 `PostMessage` 启动移动回路，这是它能稳定工作的前提。

**2. 边缘缩放同样无效**：自建 `SendMessage(HT*)` 与拖动同一病因，改回 Wails 内置（`enableResize` + `resize:<边缘>`）。

**3. 窗口/任务栏图标一直没加载**

**原因**：资源生成把图标组注册成命名资源 `"APPICON"`，而 Wails 是按 `AppIconID = 3` 用 `LoadIcon(hInstance, 3)` 取图标的（官方 `wails build` 写的是 `winres.RT_ICON`，即数字 ID 3）。资源管理器还能按命名找到图标组，所以 exe 文件图标一直正常，只有窗口拿到 `0` 后静默跳过 `SetIcon`。

**修法**：改为数字 ID 3；`--selftest` 增加 `icon.resource` 检查，防止再被改回命名资源。

**4. 深色系统下窗口描边不可见**：`body.theme-dark.is-desktop body::after` 要求 body 同时带两个 class 再嵌一层 body，永远不匹配。改为 `html.is-desktop body.theme-dark::after`（深色下白色 20%）。

**5. 侧栏品牌标记改回应用图标**：`c5d737f` 把 `--blue` 改成近黑后，那个位置变成墨底白 P。现在直接内嵌 `assets/app-icon.png`（与 exe/任务栏图标同源），不再用文字 P + 背景色模拟。

## v1.5 其它改进

- **更省**：窗口外形不再每 140ms 无条件重设区域，改为接管窗口过程、只在 `WM_SIZE` / `WM_DPICHANGED` 重裁（对齐 macUI-SolidGlass），减少重绘与投影抖动。
- **更稳**：`is-desktop` 不再依赖 `window.go` 是否已注入——旧判定一旦落空，拖拽带与窗口描边都会消失。

## 上手三步

1. 打开 `PortPilot.exe`（会自动检测正在运行的 Clash Verge）；
2. 「端口」页新建一个端口，比如 `10801`；
3. 拨开它的开关，在「节点」页选一个节点 —— 这个端口就能代理流量了。

## 亮点

- **单文件 exe**：界面与依赖全部内嵌，取它一个文件即可运行。
- **打开就是真的在监听，关闭就真的停止监听**；关窗退出后端口继续可用。工具本身不常驻：无托盘、无服务、无定时轮询。
- **选节点即时生效**：不写文件、不重载内核、不断开已有连接。
- **TUN 兼容**：下发前把 `tun:` 段按内核运行值做平，开着 TUN 开关端口不闪断；TUN 被静默关闭时自动补回。
- **订阅更新自愈**：节点改名不再打不开端口，失效的重新选一下就好。
- **重启 Clash Verge 后依然有效**：端口定义与节点选择写进当前订阅的扩展模板，Verge 每次重新生成配置都会带上，节点选择由内核的 store-selected 还原。
- **写入前备份、失败自动回滚**：内核拒绝的配置不会落盘；模板被 Verge 界面改写后也会自愈。
- **启动失败说得清**：出错会写日志并弹框说明原因，不会静默退出。
- 端口只听 `127.0.0.1`：不需要管理员权限，也不会触发防火墙提示。

## 验证

- 54 项单元测试：`node --test`
- Go 单元测试 17 项：`go test ./...`
- 宿主自检：`PortPilot.exe --selftest`（含 `icon.resource` 与内嵌应用图标检查）
- 真机端到端：`node tests/e2e-pipeline.js 10809`

## 已知限制

- 端口跟随**当前订阅**：在 Verge 里切换订阅后，端口会随新订阅重建（工具运行时会自动补一次）。
- 仅支持 Windows。
