不常驻的 Windows 桌面工具：把 Clash Verge Rev 订阅里的节点各自开放成一个本地代理端口。

## 下载

- **PortPilot-v1.1-windows-amd64.exe** —— 单个文件，双击运行，不需要安装，也不会在它旁边生成任何文件。

系统要求：Windows 10/11 ＋ Microsoft Edge WebView2 运行时（Win11 与装了 Edge 的机器都有）。
不需要管理员权限。

> 首次运行未签名程序时，Windows 可能提示「无法验证发布者」，点「运行」即可；此后再打开不再提示。

## v1.1 修复

- **新建端口后立刻选节点不再报 “Resource not found”**：以前新建的端口要先开关一次才能选节点；现在分组还没进内核时，选节点会自动先做一次完整应用把分组建出来，选择即时生效。

## 上手三步

1. 打开 `PortPilot.exe`（会自动检测正在运行的 Clash Verge）；
2. 「端口」页新建一个端口，比如 `10801`；
3. 拨开它的开关，在「节点」页选一个节点 —— 这个端口就能代理流量了。

## 亮点

- **单文件 exe**：界面与依赖全部内嵌，取它一个文件即可运行。
- **打开就是真的在监听，关闭就真的停止监听**；关窗退出后端口继续可用。工具本身不常驻：无托盘、无服务、无定时轮询。
- **选节点即时生效**：不写文件、不重载内核、不断开已有连接。
- **重启 Clash Verge 后依然有效**：端口定义与节点选择写进当前订阅的扩展模板，Verge 每次重新生成配置都会带上，节点选择由内核的 store-selected 还原。
- **写入前备份、失败自动回滚**：内核拒绝的配置不会落盘；模板被 Verge 界面改写后也会自愈。
- **启动失败说得清**：出错会写日志并弹框说明原因，不会静默退出。
- 端口只听 `127.0.0.1`：不需要管理员权限，也不会触发防火墙提示。
- 不依赖、不读取、不在界面提及任何既有的自定义脚本。

## 验证

- 35 项单元测试：`node --test`（新增选节点自愈回归测试）
- 宿主自检：`PortPilot.exe --selftest`（内嵌资源、管道发现、内核握手、文件原子写与备份、端口探测、主题）
- 真机端到端：`node tests/e2e-pipeline.js 10801`（真的开端口、代理流量、切节点、关闭、还原）

## 已知限制

- 端口跟随**当前订阅**：在 Verge 里切换订阅后，端口会随新订阅重建（工具运行时会自动补一次）。
- 仅支持 Windows。
